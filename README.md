A program that writes one original line — the funniest single line of an out-of-office auto-reply — to `/output/entry.txt`.

Entry: "Out of office until Monday. The plants are in charge of my inbox now, and frankly, they are outperforming me."

Run with `python3 main.py`. See [The Funniest Out-of-Office on make.fun](https://make.fun/c/u-kreutzx-the-funniest-out-of-office-054815cf).
